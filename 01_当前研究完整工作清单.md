# 当前研究完整工作清单

项目：ICASSP 2027 Prompt-Injection / Role-Representation Audit  
日期：2026-09-02

## 1. 研究问题

这项工作研究的是：在固定真实 Tool provenance 的情况下，role-imitation wording 会显著改变 prompt-injection 行为，但这种行为差异是否真的由 canonical role coordinates 承载。

核心区分是：

- **Calibration**：canonical role coordinate 放进完整 agent context 后，是否还保持原来的语义结构；
- **Behavioral informativeness**：即使重新校准正确，这套坐标是否真的保留了与 AttackAttempt 相关的主要行为信息。

目前的结论是：

> **Calibration ≠ Behavioral Informativeness**  
> **Human-interpretable role coordinates ≠ behaviorally useful risk coordinates**

---

## 2. 数据与实验设置

- 200 个 semantic attack cases。
- 每个 case 有 5 个 frozen role-imitation styles：System / User / Tool / CoT / Assistant。
- 共 1000 个 attack realizations。
- 所有真实 architectural provenance 始终固定为 Tool。
- contextual representation 完整 population：194 cases / 970 rows。
- within-case role pairs：1,940。
- matched clean confirmatory population：194 cases。
- 主要 statistical unit：semantic case。

## 3. 已完成工作清单

### 3.1 Role-style behavior effect

目的：确认只改变 role-imitation wording 是否会改变攻击行为。

结果：

- System：176/200 = 88.0%
- User：104/200 = 52.0%
- Tool：69/200 = 34.5%
- CoT：156/200 = 78.0%
- Assistant：130/200 = 65.0%

paired Cochran's Q(4)=206.47，p=1.52e-43。

结论：在真实 provenance 都固定为 Tool 的情况下，role-imitation wording 本身会显著影响 AttackAttempt。

---

### 3.2 Canonical role geometry：isolation → context

目的：检查原来的 canonical role coordinate 从 isolated text 放到完整 agent context 后是否仍保持。

结果：

- pooled association：r≈0.0175
- 95% case-cluster CI：[-0.0278, 0.0619]

结论：tested canonical role geometry 在 full context 中基本不保持，存在明显 context miscalibration。

---

### 3.3 Behavior-free Local re-anchoring

目的：不用行为标签，只在 destination context 中重新校准 canonical role ruler。

结果：

- global top-1 alignment：0.2415
- local top-1 alignment：0.7555
- difference：+0.5141
- 95% CI：[0.4321, 0.5992]
- 8/8 held-out seeds：local > global

结论：context miscalibration 可以通过 behavior-free Local re-anchoring 显著修复。

---

### 3.4 Canonical coordinates 的 behavioral prediction

目的：检查修复后的 role coordinates 是否真正提高 AttackAttempt prediction。

结果：

- M0 = 0.550758
- MG = 0.551233
- ML = 0.549665
- ML-M0 = -0.001093，95% CI [-0.001517, -0.000656]
- ML-MG 的 CI 跨 0

结论：Local 虽然大幅修复 alignment，但 behavioral prediction 只得到极小改善，二者并不相称。

---

### 3.5 Full hidden-state behavior model

目的：检查同一层完整 hidden representation 中是否存在更强的行为信息。

设置：

- Layer16 contextual pre-MLP payload-span mean
- hidden size：2880
- 194 cases / 970 rows
- case-grouped outer CV
- outer-training-only standardization
- L2 logistic regression
- grouped inner-CV 选择正则参数
- OOF / cross-fitted prediction

结果：

- MH = 0.439469
- MH-M0 = -0.111289
- 95% CI [-0.146564, -0.074652]

结论：完整 hidden state 中存在很强的 held-out AttackAttempt information。

---

### 3.6 Canonical role-subspace removal

目的：检查 MH 的预测增益是否主要来自 canonical role subspace。

做法：

- 将 5 个 frozen canonical role directions 居中；
- 得到 rank-4 centered role-contrast subspace；
- 从 hidden state 中正交删除这一部分；
- 按相同 held-out protocol 得到 MR。

结果：

- MH = 0.439469
- MR = 0.439557
- MR-MH = +0.000088
- 95% CI [-0.000153, 0.000335]

结论：删除 tested frozen rank-4 canonical role-contrast subspace 后，主要 behavioral signal 基本不变。

边界：这不等于删除了所有 role information。

---

### 3.7 Behavior-risk direction 的几何分析

结果：

- fold-to-fold cosine（MH）median≈0.805
- fold-to-fold cosine（MR）median≈0.803
- projection energy into canonical rank-4 role subspace：median≈0.000760，即约 0.076%
- principal angle：median≈88.42°

结论：behavior-risk direction 与 tested canonical role subspace 大体分离。

注意：几何结果只是 supporting evidence，核心证据仍是 MR≈MH。

---

### 3.8 Formal 24-layer localization

目的：排除 Layer16 只是偶然选层。

结果：

- 24/24 layers completed
- first clear layer = 1
- strongest formal layer = 15
- Layer16：MH-M0≈-0.10954
- 95% CI [-0.14773, -0.07252]

结论：behavioral predictability 不是 Layer16 偶然，在多层都可读出，Layer15 最强，Layer16 仍处于强信号区域。

边界：这是 decodability/localization，不是 causal decision layer 结论。

---

### 3.9 Behavior-risk axis 的自然语言分析

这个 axis 不是预先定义的语义维度，而是根据 AttackAttempt label，从 hidden space 中学出的线性 predictive direction。

随后在同一个 semantic case 内比较 high-risk 和 low-risk realization。

结果：

- directive-force density：high-low +3.145 / 100 words，95% CI [2.523, 3.745]
- literal-output-control density：high-low +1.272 / 100 words，95% CI [1.012, 1.542]

没有稳定支持：

- action commitment
- privilege / authority

当前最稳妥名称：

> **pre-action behavior-risk axis**

不能命名为 Instruction Adoption、Privilege Acceptance 或 causal mechanism。

结果：

- minus：0.545

## 4. 当前能支持的结论

可以支持：

- fixed Tool provenance 下，role-imitation wording 显著改变行为；
- canonical role geometry 在 full context 中明显 miscalibrated；
- behavior-free Local re-anchoring 可以修复 canonical alignment；
- alignment recovery 没有带来相称的 behavioral gain；
- full hidden state 含有强 held-out AttackAttempt information；
- 删除 tested frozen rank-4 canonical role contrasts 后，主要 predictive gain 基本不变；
- behavior-risk direction 与 tested canonical role subspace 大体分离；
- predictive signal 跨层存在；
- higher-risk projection 与 directive / literal-output-control language 有稳定关联；
- frozen Layer16 gate 在 matched confirmatory population 中有明显 operational value。

不能支持：

- role representations 不存在；
- role information 完全无关；
- behavior axis 就是 Instruction Adoption；
- behavior axis 就是 Privilege Acceptance；
- behavior axis 是 causal mechanism；
- Layer15 是 causal decision layer；
- hidden-state detector 本身就是论文 novelty；
- deployment-ready defense；
- universal cross-model conclusion。

## 5. 当前主要问题

### 5.1 Single-model generalization

目前核心结论只在 GPT-OSS-20B、一个 Tool-agent setting 和一套 canonical role construction 上验证。

这是目前最主要的外部有效性限制。

### 5.2 Novelty positioning

论文不能被理解成“又一个 hidden-state detector”。

真正的贡献是：

- calibration 和 behavioral informativeness 的分离；
- interpretable canonical role coordinates 和 behavior-relevant hidden representation 的分离。

### 5.3 Mechanistic boundary

behavior-risk representation 的 prediction 很强，但 steering 没有支持 simple causal control；自然语言分析也不足以把它识别成单一机制。

### 5.4 Defense scope

confirmatory gate 是 matched-population operational result，不是跨模型、跨 benchmark 的通用 prompt-injection defense。

## 6. 下一步工作

当前最有价值的是增加第二模型，主要解决 single-model generalization。

第二模型最低限度需要复现：

1. fixed Tool provenance 下的 five-style behavior effect；
2. canonical isolation→context transport；
3. behavior-free Local re-anchoring；
4. M0 / ML / MH / MR held-out separation；
5. 删除第二模型自己的 frozen rank-4 canonical role-contrast subspace，检查 MR≈MH 是否复现。

可选：

- compact multilayer check；
- 若核心 separation 复现，再做小规模 frozen gate sanity check。

不需要重跑：

- semantic interpretation；
- steering；
- functional annotation；
- contextual deformation；
- extensive defense tuning；
- new cases。

当前本地 Qwen3.6 只能作为候选；hidden-state / canonical-probe 路径仍需先通过 qualification，再决定是否作为正式第二模型。
